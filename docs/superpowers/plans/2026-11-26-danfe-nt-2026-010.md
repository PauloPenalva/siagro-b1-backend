## Review Focus

1. **XML sem `IBSCBS`** (nota antiga, reimpressão): o DANFE sai, com os campos novos em branco. → Task 1 e Task 3.
2. **Nota com muitos itens** (cada item ocupa até 4 linhas): os itens não invadem "Dados adicionais" na primeira página e a quebra continua certa. → Task 4.
3. **Descrição longa com `infAdProd`** mais a linha `[NCM] [cClassTrib]`: a célula cresce e as colunas de tributos acompanham a altura, sem sobrepor a linha seguinte. → Task 4.
4. **Valores grandes** (base de 9 dígitos, como `50.638,50` × 100): nenhuma coluna da grade corta o número. → Task 4.
5. **Emitente do Simples** (CRT 1, 2 ou 4): a coluna CST/CFOP mostra CSOSN como hoje e o CRT sai com a descrição certa. → Task 1 e Task 4.

```csharp
namespace SiagroB1.Reports.Services;

/// Um item da grade: cada propriedade é o texto de uma célula, com as linhas separadas por "\n".
internal sealed record DanfeRtcItem(
    string ClassTrib,      // cClassTrib ou ""
    string Bases,          // 4 linhas: ICMS, IBS/CBS, IS, IPI
    string RatesLeft,      // 3 linhas: ICMS, IBS UF, IBS MUN
    string RatesRight,     // 3 linhas: CBS, IPI, IS
    string ValuesLeft,     // 3 linhas: ICMS, IBS UF, IBS MUN
    string ValuesRight);   // 3 linhas: CBS, IPI, IS

internal sealed record DanfeRtcData(
    string Crt,
    string TotalCbs, string TotalIbsUf, string TotalIbsMun, string TotalIs,
    bool ShowIbsCbsMonoLine,
    string TotalIbsMono, string TotalCbsMono, string TotalIbsMonoReten, string TotalCbsMonoReten,
    bool ShowFcpLine,
    string TotalFcp, string TotalFcpSt, string TotalDifal, string TotalFcpUfDest,
    bool ShowIcmsMonoLine,
    string TotalIcmsMonoBase, string TotalIcmsMono, string TotalIcmsMonoRetenBase, string TotalIcmsMonoReten,
    IReadOnlyList<DanfeRtcItem> Items)
{
    public static DanfeRtcData From(NFe.Classes.nfeProc proc);
    /// Define um parâmetro por propriedade, com o prefixo "Rtc" (RtcCrt, RtcTotalCbs, RtcShowFcpLine...),
    /// e um string[] por coluna de item: RtcItemClassTrib, RtcItemBases, RtcItemRatesLeft,
    /// RtcItemRatesRight, RtcItemValuesLeft, RtcItemValuesRight (índice = posição do item em det).
    public void ApplyTo(FastReport.Report report);
}
```

**Regras que o código implementa:**
- `Crt`: `"1 - SIMPLES NACIONAL"`, `"2 - SIMPLES NACIONAL, EXCESSO DE SUBLIMITE DE RECEITA BRUTA"`, `"3 - REGIME NORMAL"`, `"4 - SIMPLES NACIONAL - MEI"`.
- Dinheiro: `N2` em pt-BR. Alíquota: formato `0.00##` em pt-BR seguido de `%` (2 a 4 casas).
- Caminhos na Zeus: item em `det.imposto.IBSCBS.gIBSCBS` (`vBC`, `gIBSUF.pIBSUF/gRed.pAliqEfet/vIBSUF`, `gIBSMun.…`, `gCBS.pCBS/gRed.pAliqEfet/vCBS`), `det.imposto.IBSCBS.cClassTrib`, `det.imposto.IS` (`vBCIS`, `pIS`, `vIS`); totais em `total.IBSCBSTot.gIBS.gIBSUF.vIBSUF`, `…gIBSMun.vIBSMun`, `total.IBSCBSTot.gCBS.vCBS`, `total.ISTot.vIS`, `total.IBSCBSTot.gMono`. Os campos internos são `decimal` não anulável: a presença se decide pelo **grupo** ser `null` ou não.
- Alíquota efetiva: grupo `gRed` presente → `pAliqEfet` (inclusive zero); ausente → `pIBSUF`/`pIBSMun`/`pCBS`.
- ICMS e IPI do item: ler `vBC`, `pICMS`, `vICMS` de `det.imposto.ICMS.TipoICMS` e `vBC`, `pIPI`, `vIPI` de `det.imposto.IPI?.TipoIPI` por reflexão (as classes variam por CST); propriedade inexistente ou `null` → `""`.
- `ShowFcpLine`: algum de `ICMSTot.vFCP`, `vFCPST`, `vICMSUFDest`, `vFCPUFDest` > 0. `ShowIcmsMonoLine`: algum de `qBCMono`, `vICMSMono`, `qBCMonoReten`, `vICMSMonoReten` > 0. `ShowIbsCbsMonoLine`: `gMono` presente e algum dos quatro valores > 0. Com a linha escondida, os textos dela ficam `""`.
