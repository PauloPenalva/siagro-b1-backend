Siagro B1 · Notificação de contrato

Como a mensagem chega no WhatsApp

Exemplos gerados a partir do formato real produzido por ContractNotificationMessageBuilder. Os dados são fictícios; o layout do texto é o que sai hoje.

Quatro eventos, quatro formatos

O corpo muda conforme o evento: criação e transições de status mostram o bloco de dados do contrato; a alteração troca esse bloco pela lista do que mudou; a fixação de preço acrescenta um bloco próprio.

O que cada marcador significa

O emoji abre a mensagem para que a pessoa faça a triagem sem ler o resto — verde entrou ou avançou, amarelo mudou, vermelho parou.

🟢Verde — incluído, aprovado, reaberto
🟡Amarelo — alterado, enviado para aprovação, aprovação retirada
🔴Vermelho — rejeitado, cancelado
⚫Preto — encerrado
🔵Azul — eventos de fixação de preço

De onde sai cada linha

Todo o texto vem do snapshot gravado em PayloadJson no momento do evento — não de uma releitura do contrato. Se o contrato mudar de novo antes do envio, a mensagem continua descrevendo o que de fato aconteceu.

Linha Origem Observação
Cabeçalho Tipo do documento + Code + evento Em negrito, entre *asteriscos* — é assim que o WhatsApp aplica negrito.
Fornecedor / Cliente CardCode + CardName O rótulo muda conforme compra ou venda.
Volume TotalVolume + UnitOfMeasureCode Três casas decimais, no padrão pt-BR.
Preço StandardPrice ou Price Omitido quando é zero: em contrato a fixar, "R$ 0,00" sugeriria um valor acordado que não existe.
Entrega, Safra, Filial Campos do cabeçalho Cada linha só aparece se o campo estiver preenchido.
Alterações Diff de OriginalValues × CurrentValues Só em edição, e apenas com campos da allow-list — colunas derivadas nunca entram.
Assinatura TriggeredBy + OccurredAt Quem disparou e quando o evento ocorreu, não quando a mensagem saiu.
Link Notifications:AppBaseUrl + rota Sempre a última linha.

Sobre a prévia do link. O link fica em último lugar de propósito: o WhatsApp monta a prévia a partir da última URL do texto, e no meio da mensagem ela empurraria o conteúdo para baixo do "ler mais".

A prévia só aparece se o endereço em AppBaseUrl for alcançável pela internet. Com o sistema publicado apenas na rede interna, o link chega como texto azul clicável — funciona para quem está na rede, sem cartão de prévia.
